# Instruções de Instalação

1. Baixe o arquivo `monta-ai-sketchup-bridge.zip`.
2. Extraia o conteúdo.
3. No SketchUp, vá em `Window > Extension Manager`.
4. Clique em `Install Extension` e selecione o arquivo `.rbz` (se gerado) ou copie a pasta para o diretório de plugins do SketchUp:
   - **Windows:** `%AppData%\SketchUp\SketchUp 20XX\SketchUp\Plugins`
   - **Mac:** `~/Library/Application Support/SketchUp 20XX/SketchUp/Plugins`
5. Reinicie o SketchUp.
