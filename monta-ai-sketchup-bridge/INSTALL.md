# Instalação do Monta AI Bridge

1. Baixe o arquivo `monta_ai_bridge.rbz`.
2. No SketchUp, vá em **Window > Extension Manager** (Windows) ou **SketchUp > Extension Manager** (Mac).
3. Clique em **Install Extension**.
4. Selecione o arquivo `.rbz` baixado.
5. O menu **Monta AI** aparecerá na barra superior.

## Como gerar o arquivo .RBZ
1. Compacte o arquivo `monta_ai_bridge.rb` e a pasta `lib/`, `ui/`, `examples/` em um arquivo ZIP.
2. Renomeie a extensão de `.zip` para `.rbz`.
