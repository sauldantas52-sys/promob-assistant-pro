# Monta AI Bridge para SketchUp (Beta)

Ponte de arquitetura e engenharia para preparar ambientes para o Promob e Monta AI.

## Funcionalidades
- Tags Industriais Automáticas (00_REFERENCIAS a 09_NAO_FABRICAVEL).
- Identificação de Ambientes, Paredes, Portas e Janelas.
- Exportação de manifesto JSON com metadados geométricos.
- Planta baixa em escala (1:20 / 1:25).

## Segurança Industrial
- **machining_blocked: true** (Inviolável).
- Sem geração de código de máquina (CNC/MPR/G-Code).
